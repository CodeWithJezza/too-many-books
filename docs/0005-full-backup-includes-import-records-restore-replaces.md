# Full backup includes Import records; restore replaces everything

The full backup is a single JSON file containing everything: Works, Readings, Series, Genres, Shelves, Metadata, and all Import records with their last-imported field values. Import records must be included because without them a restored library would treat every Libby Loan and Goodreads row as new, refilling the Inbox with items already reviewed or dismissed. A separate one-way CSV of reading history is offered for spreadsheets and is not importable. Restoring replaces the whole library after confirmation and does not merge, because merging two libraries would be a second de-dupe problem and v1 is single-user and single-device. The app prompts for a backup when enough has changed since the last one, since there is no server copy.

Amendments, 2026-09-30. The backup format is still version 1. Loans gained optional fields (`source`, `readingId`, optional `borrowed`) additively, and `validateBackup` now rejects a file in which a Loan's `readingId` is not a Reading in the file. Settings also has Erase library, which empties every table, including Import records and cached lookups, after confirmation, so the next import proposes everything again. Sample books are seeded once per device (a localStorage flag), so neither erasing nor removing them brings them back.
