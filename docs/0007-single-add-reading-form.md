# Adding a Reading is one form; Works are never a separate creation step

The Add screen is built around the act of adding a Reading, not around creating a Work first. Its first field is a title box that searches the reader's existing library and Open Library as they type, so a re-read or a book already owned attaches to the existing Work (via the matching rules in the Work entry in CONTEXT.md) instead of duplicating it; if nothing matches, title and author can be entered by hand. A status selector (Reading now, Finished, DNF, Want to read) governs which fields the form shows next: Reading now, Finished, and DNF show format, start date, finish date (day/month/year/unknown), rating, and a short review, with only title and status required and dates defaulting to today where sensible; Want to read hides the Reading fields entirely, since it has no Reading yet. A Work is always created alongside one of these outcomes and never as a bare, empty record.
